# Dữ liệu

Thư mục này giữ dữ liệu nguồn tabular. Hai CSV được workspace cài sẵn là Wisconsin Breast Cancer và Wholesale Customers, được phục vụ qua [public/](../public/). Fixture nhỏ nằm ở [tests/fixtures/](../tests/fixtures/). Dữ liệu triển lãm được Vite đóng gói từ [Welcome](../frontend/src/features/welcome/data/) và [Portal](../frontend/src/features/portal/data/).

Chạy `npm test` để kiểm tra số hàng, định danh, tệp nhị phân và hash của dữ liệu mẫu. Giữ nguyên tên CSV mặc định vì API, test và script có tham chiếu.
