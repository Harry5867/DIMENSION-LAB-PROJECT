# Scripts

Chạy từ root. [generate-case-studies.ts](generate-case-studies.ts) dựng case studies từ CSV công khai bằng PCA và GMM. [prepare-terrain-grid.mjs](prepare-terrain-grid.mjs) tạo lưới nhị phân và metadata Terrain. [fetch-story-photos.py](fetch-story-photos.py) cập nhật ảnh và ghi nguồn. [inventory-legacy-mongo.mjs](inventory-legacy-mongo.mjs) kiểm kê dữ liệu MongoDB cũ. [data_loader.py](data_loader.py) xử lý dữ liệu MNIST thô.

Đối chiếu diff và chạy `npm test` sau khi tái tạo asset. Thực hiện tác vụ nguồn mạng hoặc cơ sở dữ liệu khi có cấu hình dev phù hợp.
